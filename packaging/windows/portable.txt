RabiCraft portable mode

While this file sits next to rabicraft.exe, RabiCraft keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the RabiCraftData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move RabiCraft with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\RabiCraft and
%LOCALAPPDATA%\RabiCraft) instead. If RabiCraftData can't be written (for example on a read-only
drive), RabiCraft says so and uses the per-user folders instead.
